# Lyric Studio icon

The approved concept and composed preview are kept here. The editable Icon Composer document is `../icon.icon`. Its transparent PNG layers were generated with the built-in image tool and resized to a shared 1024-pixel canvas. Icon Composer supplies the indigo background and platform shape.

Generation prompts: extract the three purple lyric ribbons, reconstructing portions obscured by the note, preserving canvas, positions, scale and colors on transparent alpha; separately extract only the pearl musical note with the same canvas and placement on transparent alpha. Remove background and other elements from both layers.

The first layer in Icon Composer is the foreground. `project.yml` includes the icon as a resource and selects `icon` as the app icon for both build configurations.

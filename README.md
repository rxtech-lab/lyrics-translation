# Lyric Studio

Native SwiftUI document app for macOS 26+, using RxAgentSDK. Open `LyricStudio.xcodeproj`, select LyricStudio, and Run. Requires the sibling SDK checkout at `../rxlab/RxAgentSDK` (Swift 6.3). Regenerate project settings with `xcodegen generate`.

1. Add original lyrics in the Original sheet.
2. Set the target language and each specialist's client/model in Agents. Model pickers load through RxAgentSDK, with a Provider default option. Codex and Claude use availableModels() (including SDK-managed cache/fallback behavior). ACP uses SDK process/JSON-RPC APIs for initialize + session/new discovery, supporting grouped configOptions and legacy availableModels, with a 30-second timeout and process cleanup; no prompt is sent. Reload models retries discovery. Install and authenticate Codex/Claude Code separately; ACP accepts an absolute executable path and newline-separated arguments.
3. Translate all, or select a line and translate it. The pipeline determines artistic direction, plans target-language rhyme groups across the song, estimates meter and rhyme, translates, reviews, and revises. Each candidate must pass a separate model-based rhyme check before saving; at most two repair attempts are made before stopping with the previous translation preserved. This enforces a model verdict, not a deterministic phonetic guarantee. Click an original-rhyme entry in line details to preview related original and translated lines in a popover, or jump to a related line. Stop cancels the active SDK turn and preserves completed lines.
4. Review each line in its dedicated sheet, edit the text, approve it, or leave feedback and retranslate.
5. Open Usage to see token usage and cost. Every formatting or translation run is recorded as a session in the document, with each agent call's input, cache read/write and output tokens. Costs are calculated with live per-token prices from Vercel AI Gateway's public model list (`https://ai-gateway.vercel.sh/v1/models`, no key needed, refreshed every 15 minutes or on demand), so they are AI Gateway list-price estimates, not your Codex/Claude subscription bill. Switch between all sessions and a single session, and view totals by agent, by session or per call. Calls whose model has no gateway price (for example an unreported provider default) are listed but not priced. Conversation-sheet chats are not counted.
6. Open Karaoke to sing along with the Apple Music recording and make word-level karaoke subtitles. Choose Song searches the Apple Music catalog and links the recording to the document. Time Words lists every line as word chips: start the song (Return), then hold Space while each word is sung — press marks the start, release marks the end and moves to the next word. Delete undoes the last word and rewinds 2 s, ↑ clears and redoes the line, clicking a word moves the cursor there. Slow the song to 0.5×/0.75× and set a reaction offset for precision. Time the Original or the Translation track; Chinese and Japanese are timed per character. Timings are saved per line and reset automatically when that line's text changes. The karaoke preview fills each word as it is sung and shows the other track underneath. Export as Enhanced LRC (`<mm:ss.xx>` per word) or Apple-Music-style word-timed TTML (with the other track as `x-translation`).
7. Save a `.lyricstudio` document with standard File commands. Versions preserve line snapshots before edits and after each completed translation; restoring checkpoints preserves the current draft first.

The Conversation sheet uses SDK AgentChatView with song context and the translator's client/model. Conversation is advisory and currently session-only; it does not automatically edit document lines. Translation activity is also session-only. Original text, annotations, settings, feedback, translations and versions are saved in the document.

Adapted from universal-translation's rhythm/rhyme/translation/review pipeline. Meter is a linguistic estimate, not audio beat detection. Multiple internal and end rhyme annotations are supported. Actual singability needs human singing review. The app runs local CLI clients without an app sandbox; it requires no Vercel API key or upload service.

Apple Music playback uses MusicKit's `ApplicationMusicPlayer` and needs an Apple Music subscription. Enable the **MusicKit** App Service for `app.rxlab.LyricStudio` in the Apple Developer portal and build signed with that team; unsigned builds cannot obtain a MusicKit developer token, so search and playback fail with an error.

Validation: unsigned Debug Xcode build passed. Live provider runs, cancellation against each installed client, document UI and visual layout have not yet been exercised. Distribution signing/notarization is not configured.

## Lyric video

Open **Lyric Video** in the toolbar and choose Original or Translation. Use **Preview with Apple Music** for the song linked in Karaoke, or import a local audio recording matching the karaoke timings. Apple Music previews follow the MusicKit playback clock and support play, pause and restart; closing the sheet pauses playback. Use **Import Audio for Export** to switch to exportable local audio. All words in the selected track need ordered start/end timings within the recording. The full-height sheet previews animated word highlights, line entrances, a moving gradient and the other language as subtitles. Play, pause or restart, then **Export MP4** for 1920×1080, 30 fps H.264 video with audio. Preparation/export progress appears in an overlay with cancellation. Apple Music streams are not embedded; supply an audio file.

Uses the sibling `../rxlab/film-workflow/Packages/RxRemotion` package (RxRemotion and RxRemotionUI), with bundled Remotion compiled in WebKit and native AVFoundation export. No Node runtime, API key or upload is needed. Temporary compositions and audio copies are removed when the sheet closes; video settings/audio selection are session-only.

Apple Music lyric-video integration: unsigned Debug build passed; live MusicKit authorization, playback synchronization and movie export have not been verified in this change.
